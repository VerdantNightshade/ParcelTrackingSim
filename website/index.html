About

A parcel tracking simulator written in Java. The program tracks parcels through four hubs and logs each step.

  1. Dispatch
  2. Sorting Facility
  3. Out-for-Delivery
  4. Delivered

Features

  • Three parcel speeds: Standard, Express, and Overnight.
  • Invalid tracking IDs are rejected with an exception.
  • The manifest and the status log are saved in text files.
  • The tracking history of a parcel prints in the terminal.
  • Core Java only, with no database.
