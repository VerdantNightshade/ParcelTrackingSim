\chapter{Testing \& Results}

\section{Testing Strategy \& Test Cases}
The tests use core Java only. There is no test library. One call runs all of
them:

\begin{lstlisting}[style=console]
bash test/run-tests.sh
\end{lstlisting}

The script runs three scripts in order and stops at the first step that fails.
The GitHub workflow runs the same three scripts, one step each, on every push
and pull request to the main branch:
\begin{enumerate}
\item \textbf{Build test} (\texttt{build.sh}). The script compiles all files in \texttt{src} and
checks that all 12 class files exist.
\item \textbf{Test compile} (\texttt{compile-tests.sh}). The script compiles the test classes in
\texttt{test} against the compiled program.
\item \textbf{Unit tests} (\texttt{unit-tests.sh}). The script runs each test class. Each test class
tests one class of the program.
\end{enumerate}

A test class has several test methods. A test method calls the method under
test and compares the result with the expected value. A failed check prints the
expected value and the actual value, and the other checks still run. The helper
class \texttt{TestSupport} holds these checks. Tests that use files run in a
fresh temporary folder, so they do not change the real data files.

\section{File Persistence Verification}
After the run in Example 1 and Example 3, the program created two files.
Fig.~\ref{fig:files} shows their content. The manifest has the last hub of each
parcel. The status log has one line for each milestone, in the order they
happened.

\begin{figure}[h]
\begin{lstlisting}[style=console]
manifest.txt
ORD1001,Express,Delivered
ORD1002,Standard,Dispatch
ORD1003,Overnight,Dispatch

status-log.txt
ORD1001,Dispatch,Wed Nov 25 19:54:50 IST 2026
ORD1002,Dispatch,Wed Nov 25 19:54:50 IST 2026
ORD1003,Dispatch,Wed Nov 25 19:54:50 IST 2026
ORD1001,Sorting Facility,Wed Nov 25 19:54:50 IST 2026
ORD1001,Out-for-Delivery,Wed Nov 25 19:54:50 IST 2026
ORD1001,Delivered,Wed Nov 25 19:54:50 IST 2026
\end{lstlisting}
\caption{Content of the two text files.}
\label{fig:files}
\end{figure}

Then the program started again and the user tracked \texttt{ORD1002}. The program
showed the history, the delivery days (5), and the fee (100.0) from the saved
files. So the program loads the manifest and the status log correctly.
