{\bfseries\fontsize{14}{17}\selectfont ABSTRACT}
\end{center}
\vspace{0.5cm}

This work is about a brief summary of the project. The objective of this report
is to address the problem of tracking parcels through a courier network and to
propose a solution using object-oriented programming in Java.

The work includes a study of the relevant concepts, the design of the class
model, implementation using the chosen tools, and an analysis of the results.

The outcomes show the main results of the project. The report concludes with
possible future extensions and improvements of the proposed work.

\vspace{1cm}
\noindent\textbf{Keywords:} object-oriented programming, Java, parcel tracking,
simulation, file persistence
