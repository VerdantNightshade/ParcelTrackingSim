\vspace{0.5cm}

This report describes the Courier and Parcel Tracking Simulator, a command-line
program written in core Java. The program tracks parcels through four hubs:
Dispatch, Sorting Facility, Out-for-Delivery, and Delivered.

The program uses inheritance for three shipment speeds (Standard, Express, and
Overnight), a custom exception for invalid tracking IDs, and text files that
save the parcels and each tracking milestone. Unit tests check each class.

\vspace{1cm}
\noindent\textbf{Keywords:} object-oriented programming, Java, parcel tracking,
simulation, file persistence
